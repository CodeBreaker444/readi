Clients of your company can have their own login. A user with the **Client** role goes straight to the client area and sees only the information about their own missions.

---

## Dashboard

The dashboard gives an overview of the work done for the client:

- **Total missions**, **flight hours**, **distance flown (km)** and **systems used**
- Missions by status
- The systems and drones used
- Flights per day and per month

A separate **Analytics** page shows the same information in more detail over time.

---

## Missions

The Missions page lists the client's missions with code, name, status, pilot, drone, scheduled time, duration and location. Clients can search and filter by status (Planned, In Progress, Completed, Cancelled, Aborted).

Select a mission to see its details: actual start and end, distance flown and notes.

---

## Scheduled Flights

**Scheduled Flights** shows the flights planned for the client through [Slot Booking](/docs/modules/slot-booking). It lists the approved slots of every slot group created for this client, one day at a time. It opens on today; use the arrows, **Today** or the date picker to see another day.

Each flight shows:

| Item | Notes |
|---|---|
| Time | Start and end of the slot, in the site's time zone. When that differs from the client's own time zone, the zone is shown under the time |
| Status | **Upcoming**, **In progress** or **Finished**, based on the slot's time. It updates on its own while the page is open |
| Pilot | Picture, name, email and phone of the pilot assigned to the slot |
| System | The system chosen for the slot group, if any |
| Weather | Calm, moderate or tough, when the slot group has a system with a location |
| Missions | The client's own missions the pilot linked to the slot, with their progress (Scheduled, In progress, Done, Aborted) |

Totals at the top count the day's flights and how many are upcoming, in progress or finished. The page refreshes every minute.

What clients do **not** see:

- Slots without an approved pilot, and pending or rejected requests
- Slot group names and any other slot booking settings
- Slot groups with a future publish date, until they are published
- Slots of other clients, and missions of other clients linked to the same slot

## Events

**Events** shows the incidents and anomalies reported on the client's missions, from the [Event Logbook](/docs/modules/logbooks). Open an event to see its details, a map of where it happened and its attachments. Clients can look at events but cannot change or delete them, or add media.

---

## Requesting a flight

Clients can ask for a new flight from **Request Flight**. They fill in:

| Field | Notes |
|---|---|
| Mission type or Target / Area | At least one is required |
| Preferred start time | |
| Priority | High, Medium or Low |
| Operator | Company or person responsible for the request |
| Localization | Position, direction, and starting and ending points |
| Waypoint | Latitude, longitude and altitude |
| Notes | Special requirements |

After sending, Readi checks the waypoint against the operation zones of the systems assigned to the client. If it is inside the zones of at least one system, the client sees a confirmation. The request appears for your team under **Flight Requests → External**, where an OPM links it to a mission or denies it (see [Operations → Flight Requests](/docs/modules/operations#flight-requests)).

If the waypoint is outside the zones of **every** system of the client, the request is **rejected** straight away. The client sees an error with the reason, which names the nearest system and its distance. The form is kept, so they can correct the location and send it again. Requests without a waypoint are not checked.

## Permissions

The **CLIENT** role only has access to the Client Portal. It cannot open any other module, and it only ever sees its own company's data. These permissions are fixed for the CLIENT role and **cannot be customised** in the role permissions editor.

| Area | Read | Write / edit | Delete | Customisable in role permissions editor |
|---|---|---|---|---|
| Dashboard | Yes | No | No | No |
| Missions | Yes | No | No | No |
| Scheduled Flights | Yes | No | No | No |
| Events | Yes | No | No | No |
| Analytics | Yes | No | No | No |
| Request Flight | – | Yes (submit a request) | No | No |
| Profile | Yes | Yes (own profile) | No | No |

For all other roles, see the [role permissions reference](/docs/business-logic/role-permissions).

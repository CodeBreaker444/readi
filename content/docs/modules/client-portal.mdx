---

Clients of your company can have their own login. A user with the **Client** role goes straight to the client area and sees only the information about their own missions.

---

## Dashboard

The dashboard gives an overview of the work done for the client:

- **Total missions**, **flight hours**, **distance flown (km)** and **systems used**
- Missions by status
- The systems and drones used
- Flights per day and per month

A separate **Analytics** page shows the same information in more detail over time.

---

## Missions

The Missions page lists the client's missions with code, name, status, pilot, drone, scheduled time, duration and location. Clients can search and filter by status (Planned, In Progress, Completed, Cancelled, Aborted).

Select a mission to see its details: actual start and end, distance flown and notes.

---

## Events

**Events** shows the incidents and anomalies reported on the client's missions, from the [Event Logbook](/docs/modules/logbooks). Open an event to see its details, a map of where it happened and its attachments. Clients can look at events but cannot change or delete them, or add media.

---

## Requesting a flight

Clients can ask for a new flight from **Request Flight**. They fill in:

| Field | Notes |
|---|---|
| Mission type or Target / Area | At least one is required |
| Preferred start time | |
| Priority | High, Medium or Low |
| Operator | Company or person responsible for the request |
| Localization | Position, direction, and starting and ending points |
| Waypoint | Latitude, longitude and altitude |
| Notes | Special requirements |

After sending, the client sees a confirmation. The request appears for your team under **Flight Requests → External**, where an OPM can accept or deny it (see [DCC Integration](/docs/business-logic/dcc-integration)).

---

## Permissions

The **CLIENT** role only has access to the Client Portal. It cannot open any other module, and it only ever sees its own company's data. These permissions are fixed for the CLIENT role and **cannot be customised** in the role permissions editor.

| Area | Read | Write / edit | Delete | Customisable in role permissions editor |
|---|---|---|---|---|
| Dashboard | Yes | No | No | No |
| Missions | Yes | No | No | No |
| Events | Yes | No | No | No |
| Analytics | Yes | No | No | No |
| Request Flight | – | Yes (submit a request) | No | No |
| Profile | Yes | Yes (own profile) | No | No |

For all other roles, see the [role permissions reference](/docs/business-logic/role-permissions).

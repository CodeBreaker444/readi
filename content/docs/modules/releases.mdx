The **Releases** page lists every version of Readi with what changed, so you always know what is new.

---

## Finding a release

- The list on the left shows each version with its title and date. The newest is marked as the latest.
- **Search releases** looks in the version number and title.
- Use the version dropdown or **Filters** to show only one type of release.
- The bottom of the list shows how many releases match, for example "Showing 3 of 12 releases".

---

## Reading a release

Pick a version to read it. The details are split into tabs:

| Tab | What it holds |
|---|---|
| **What's New** | New features |
| **Improvements** | Things that now work better |
| **Bug Fixes** | Problems that were fixed |
| **Details** | Everything else about the release |

A tab only appears when the release has something for it. Use the download button to save the release notes as a file.

## Features

### Recurrent Mission Support

Added support for recurrent missions in the mission planning system. Missions can now be configured to repeat on a schedule, allowing for automated mission planning and execution for recurring operations.

### Enhanced Audit Logging for Evaluations

Improved audit logging for evaluation-related actions with enhanced user context. The following functions now include userId, userName, userEmail, and userRole parameters for better tracking:
- `updateEvaluation` - Enhanced with user context and evaluation code metadata
- `updateEvaluationTask` - Added user context and task name in descriptions
- `sendEvaluationCommunication` - Enhanced with recipient name and user context

### Manual Flight Log Updates

Added support for manual flight log updates in the flight log component, allowing users to manually update flight records when needed.

## Bug Fixes

### Mission Planning Issue at New Mission

Fixed an issue where mission planning would fail or behave incorrectly when creating a new mission. The planning system now properly initializes and handles new mission creation without errors.

### Planned Date Issue

Fixed an issue with planned date handling in missions. Dates are now correctly processed, stored, and displayed throughout the mission lifecycle, ensuring accurate scheduling and timeline management.

## Features

### Evaluation Communication Search and Filters

Added search for new communications within an evaluation, along with a role-based filter for task assignments.

### Evaluation Communication History Table

Added a new table below task completion listing all communications made for an evaluation request.

### Searchable Communication Selector

Added a searchable dropdown list when sending communications from the planning dashboard.

### Checklist View Option

Added a view option for each completed checklist within task completion.

### Maintenance Component Color Coding

Manually updated maintenance components are now shown in a different color than automatically updated ones (e.g. day-based components), making it easier to tell them apart.

### Maintenance Prefill

Maintenance values are now prefilled by default, with users able to adjust them only when needed.

### Flight Log Cloud Offloading

Flight logs now automatically offload to secure cloud storage if the initial download fails, instead of only retrying a limited number of times.

### Admin Account Reactivation Email

When a company's primary admin email is changed, an activation email is now automatically sent if the previous admin never activated their account.

## Bug Fixes

### Audit Log Description Search

Fixed audit log filtering so searching by keywords (e.g. "position") returns matching records across all sections, not just one.

### Audit Log Previous Value Missing

Fixed audit log entries for position changes so the previous value is now recorded and displayed alongside the new one.

### Evaluation Audit Logs Not Updating

Fixed evaluation audit logs so actions taken during an evaluation are now properly recorded.

### Planning Dashboard Audit Logs Not Updating

Fixed audit logs on the planning dashboard so they now reflect the latest actions.

### Evaluation Year Reference Missing

Fixed the evaluation request edit form so the year reference is now correctly filled in.

### Mission Logbook Observer Assignment

Fixed an issue preventing an observer from being added to the mission test logbook the same way a pilot can.

### Import Mission Options Not Loading

Fixed an error that prevented mission planning options from loading during mission import.

### Mission Procedure Status

Fixed an issue where a mission's procedures showed as fully complete even though one task was still pending.

### Duplicate Maintenance Updates

Fixed maintenance so it only applies once per update instead of being applied repeatedly, with values shown only on the next cycle.

### Client Edit Error Messaging

Fixed client editing so validation errors now point to the specific field that needs attention, instead of a generic error.

### Profile Update Repeating

Fixed profile updates so clicking save no longer keeps re-submitting the update.

## Improvements

- Enlarged task completion modals across evaluations and the planning dashboard for better visibility
- Removed the documents folder step when moving an evaluation to the planning dashboard
- Restricted drone changes during mission import to preserve import accuracy
- Renamed "No" to "Close" in the complete procedure tasks modal on the daily board
- Mission state transitions no longer require a DCC start step unless the mission was requested through DCC
- Import mission and attach flight log lists now show the latest 20 entries
- Enlarged the import mission modal for easier review
- Added the option to revert maintenance when a mission is deleted
- Past and next mission views on the dashboard now reflect the mission's overall status rather than the assigned pilot's status

## Features

### Department Filtering for Team Members

Team profiles now include an editable department field, and the team management dashboard lets you instantly filter the team list by department.

### Manager Authorization for Deletions

Deleting a record now requires entering a valid manager authorization code first, adding an extra safeguard against accidental data loss.

### Pilot Certifications in Mission Setup

When setting up a new mission, you can now view a pilot's qualifications and certifications directly on the pilot selection screen, without leaving the setup flow.

### Clickable Mission IDs in Flight Logbook

Mission IDs in the flight logbook are now clickable links. Clicking one opens a popup with the complete details for that mission.

### Mission Duration Tracking

The mission view now displays elapsed flight duration alongside distance, making it easier to track how long a mission has been running or how long it took.

### Automatic Logbook Sorting by Start Time

Flight logbook summaries now sort by start time automatically, in either chronological or reverse-chronological order, and your chosen sort order is remembered the next time you visit.

### New Mission Scenario Types

Mission creation now supports two additional standard scenario types, set up with the same fields and checks as existing mission types.

### Automated STS Declaration Retrieval

Official STS declaration documents can now be fetched automatically from d-Flight and viewed directly in the platform, instead of requiring a manual download.

### Flexible Logbook Exports

Flight logbook exports can now be filtered by date range and system before downloading, making it easier to generate the exact report you need.

## Features

### Mission Codes in Dashboard Tables

The mission tables on the dashboard now show the same mission code used everywhere else in the app, instead of an internal reference number.

### Department Selection in Your Profile

Your department is now chosen from a dropdown list of your company's departments, instead of being typed in freely, so it always matches what your company has set up.

### Team Member Profile Photos

The team management list now shows each person's actual profile photo instead of just their initials, wherever one has been uploaded.

## Bug Fixes

### Mission Status Showing Incorrectly on Dashboard

Fixed an issue where a completed mission could show the wrong status, such as "In Flight," on the dashboard. Mission status updates now always reflect your company's own status setup correctly.

### Mission Dates Showing in the Wrong Format

Fixed dates on the dashboard and in the flight logbook so they now display in day/month/year order and in your own timezone, instead of the previous month/day/year format.

### Flight Logbook Sorting by Start Time

Fixed sorting by start date in the flight logbook so it works correctly with the corrected date format.

### Dashboard Mission List Jumping

Fixed the mission lists on the dashboard so the page navigation controls stay in place, instead of jumping upward when a page has fewer missions than usual.

### Department Not Saving on Profile

Fixed the profile page so changes to your department are now actually saved, instead of being silently discarded when you clicked save.

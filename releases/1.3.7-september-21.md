## Bug Fixes

### Dashboard Failing to Load

Fixed an issue where the main dashboard could fail with a server error instead of loading normally, even though the underlying mission data was available.

### Missions Showing Incorrect End Times on the Calendar

Fixed an issue where some missions on the Operations Calendar could show an end time earlier than their start time, causing them to display incorrectly or not show up properly on the calendar.

### Drone Status Inconsistent Across Modules

Fixed an issue where a drone could show as operational in Systems even while it had an open maintenance ticket correctly marking it as in maintenance elsewhere in the app. Manually setting a drone to operational can no longer hide a real, active maintenance issue.

### DCC Mission Retries Rejected as Duplicates

Fixed an issue where ReADI rejected a mission request from DCC if the same mission ID had already been received — for example, when DCC retried a request after a timeout. These are now treated as an update to the existing mission request instead of being rejected.

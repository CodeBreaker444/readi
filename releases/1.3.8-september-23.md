## Bug Fixes

### Maintenance Dashboard Components Resetting

Fixed an issue where components on the Maintenance Dashboard could reset unexpectedly, causing maintenance counters to lose their progress. Component values now persist correctly.

### Maintenance and Insurance Expiry Email Notifications

Fixed an issue where email notifications for upcoming maintenance due dates and insurance expiry were not being sent correctly. These reminders are now delivered as expected.

### XLSX Export Failing to Download

Fixed an issue where exporting data to an XLSX file could fail or produce a file that could not be downloaded. XLSX exports now download and open normally.

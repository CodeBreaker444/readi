## Improvements

### More Detail in the New Mission Dropdowns

The Drone/System dropdown on the New Mission screen now shows each option as "System Name – Drone Component Name – Drone Serial Number" instead of just the system name, so drones are easy to tell apart at a glance. The Pilot dropdown now also shows each pilot's department alongside their name.

### Visual Observer Name in the Flight Logbook

The Flight Logbook list now shows the Visual Observer's name underneath the pilot's name for each flight, and the same detail is included when exporting the logbook.

### Nickname Locations with a Pseudo Name

Wherever a location is selected or created from the map, you can now give it a short Pseudo Name so it's easier to recognize the next time you pick it.

### Attach Documents to Multiple Drone Systems

Repository documents can now be linked to more than one drone system at once. The document form's Component field is now a checkbox-based multi-select, so a single manual or certificate can cover every drone it actually applies to instead of being uploaded separately for each one.

### Linked Components Shown on System Files

The Files/Documents section under Manage Systems now shows which component(s) each document is linked to as pills next to the document, and adds a quick "View" option to preview PDFs and images without downloading them first.

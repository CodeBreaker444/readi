## New

### Event Logbook

A new Event Logbook sits under the Flight Logbook in the sidebar. Pilots can report incidents such as an equipment malfunction, GPS signal issue, obstacle, weather, bird activity, unexpected landing or loss of control. Each report includes the drone, an optional mission, the location on the map, the takeoff time, notes, and photos, videos or PDFs.

Pilots only see their own drones and missions, and their own reports. Clients can see the events reported for their missions in the client portal.

### Notify Clients Automatically

Admins can use the settings icon on the Event Logbook page to send every new event to a client's own system. A connection can be set up for one client or for all clients, and limited to certain event types. It can be tested at any time, and a log shows whether each delivery worked.

## Improvements

### Easier Drone and Mission Selection

The drone and mission lists when reporting an event can be searched and are split into pages. Each drone shows its main drone component and serial number, like in New Mission.

## Fixes

### Closing a Ticket No Longer Brings Back Expired Components

Closing a ticket no longer makes an expired or decommissioned component Operational again.

### Readable PDF Export for Tickets

The ticket PDF is easy to read again. Before, 16 tickets produced 22 pages with the text running vertically.

### Complete Excel and CSV Exports

Excel and CSV exports now include every component and serial number for tickets with more than one component.

### Matching Ticket Times

The ticket logbook and the event history now show the same time.

### Correct Status in the System Picker

Systems that are in Maintenance are no longer shown as Operational in the system picker.

### Search by Component Serial Number

Searching for a component serial number now finds the matching system.

### Who Did It in Ticket History

The assignment and closure history now shows who performed each action.

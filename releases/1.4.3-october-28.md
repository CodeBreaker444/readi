## New

### Expired Means Expired

When a component passes its expiry date or reaches its flight or flight-hour limit, it is now retired for good. It cannot be made Operational again, extending its expiry is refused, and no maintenance ticket can be created for it. To get the system operational again, set the component to Decommissioned, remove it from the system, or move it to the warehouse.

### Who Changed What

The activity log now records who changed a system's status and what it changed from and to. For components it records changes to status and expiry the same way, and notes when a system's status changes because a component left maintenance. Added components also show their expiry date in the log.

## Fixes

### Same Status Everywhere

When creating a maintenance ticket, the system list could show a system as Operational while Manage Systems showed it as Not Operational, for example when a component had expired. Both now show the same status.

### Edits Keep Your Details

Saving a system without touching every field no longer clears details such as its client, location or activation date. Saving a component without choosing a status or expiry type now keeps what it already had, instead of resetting to Operational.

### Whole-Number Mission Planning Versions

The version on a mission planning request must now be a whole number of 1 or more. Decimals and empty values are no longer accepted.

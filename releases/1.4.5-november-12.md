## New

### Slot Group Booking

A new **Slot Booking** page under **Operations** lets the Operations Manager (OPM) open a group of time slots and lets pilots request them. The OPM approves or rejects each request, can attach a PDF to an approved slot, and sets company defaults in Slot Settings. **Approved Slots** lists the approved jobs, and an **Audit Log** (OPM, Admin and Super Admin) records every change to groups, slots and bookings. Pilots and managers are notified by email and in the app.

### FlytSense Events

The event logbook has a **FlytSense events** tab with events detected automatically on your video streams. Each event shows its type, what was detected, the confidence and an image. Images are now saved to ReADI storage, so they stay available after the original link expires. You can send feedback on a detection, delete an event, and add the clients to notify as contacts. Pilots with recent-flights access can also open flight pictures from the Control Center.

### Event Webhook Includes the System

Event webhooks now include the system selected for the mission, with its components and serial numbers, so receivers can identify the exact hardware.

### Documentation as PDF

Every documentation page has a **Download this page (PDF)** button, and the introduction page also offers **Download all docs (PDF)**.

### Copy Error Messages

Error notifications now have a **Copy** button, so you can paste the message to support instead of taking a screenshot.

## Improvements

### Faster Weather Layers

Weather layers in Drone ATC are now cached and refreshed in the background, so the map loads them faster and no longer waits on the weather provider.

### Control Center Setup in the User Form

The Control Center section of the Edit User form was reworked, and a Control Center organisation can now be removed from a user. Removals are recorded in the activity log.

### Steadier Live Connection

The live connection used by Drone ATC and flight tracking was optimised to use less bandwidth and to reconnect more reliably.

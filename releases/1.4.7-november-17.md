## New

### Today's Schedule

Pilots have a new **Today's Schedule** tab in Slot Booking. It lists every slot the pilot is **approved** for today, in time order, as a timeline. "Today" is the date at each slot group's site, so a night slot from yesterday (for example 22:00–06:00) stays on the list until it ends.

- **Header and tiles:** the date, a live clock and the last refresh time, with a shortcut to the Daily Board. Tiles show slots today, hours on duty, missions done out of linked, missions in progress and slots that need attention.
- **Banner:** red when a slot needs attention or some of today's missions are not linked to a slot yet, green when every slot is on track.
- **Slot cards:** time, duration, slot group, client, system, weather, the slot's state and a timer bar that fills as the slot's time passes.

### Link Missions to a Slot

Pilots and the OPM can link the pilot's missions of the day to a slot. The dialog shows the full mission details, marks missions planned inside the slot's time and pre-selects them. A mission belongs to one slot only, a different client shows a warning, and a link can be removed with the **×** on the mission. Every change is written to the slot's audit log.

### Live Mission Progress

Mission status comes straight from the Daily Board. Starting or finishing a mission there shows on Today's Schedule within 20 seconds, when the browser tab is shown again, or at once with **Refresh**. Slot states are: No mission linked, Ready, No progress, In progress, Next mission pending, Completed and Incomplete.

## Improvements

### Loading Placeholders

Every Slot Booking tab now shows a placeholder that matches its own layout (cards, tiles, calendar, tables) while data loads, instead of a blank area.

### Steady Tab Bar

Switching Slot Booking tabs no longer hides the tab bar for a moment, and managers no longer briefly see the pilot tab names when the page first opens.

### Time Zones

The Daily Board and the auto-abort job now use the same site-based day as Today's Schedule, so a night slot is not cut off at midnight.

### Documentation

The Slot Booking, Operations and database tables documentation pages describe Today's Schedule and the new slot-to-mission link.

## Fixes

### Update Password Autofill

Browsers no longer fill saved credentials into the new and confirm password fields when an admin or a user updates a password. The fields are marked as new passwords, in both the team and the user management dialogs.
